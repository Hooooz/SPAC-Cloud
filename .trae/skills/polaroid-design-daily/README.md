# Polaroid Design Daily - 拍立得周边产品设计日报生成器

## 简介

这是一个专门用于收集拍立得周边产品设计元素和灵感的 AI skill，能够自动生成高质量的设计日报。

## 功能特点

### 🎯 核心功能
- **多源数据收集**: 通过 Tavily Search API 从多个设计网站和电商平台收集数据
- **智能分类**: 自动将设计元素分类为色彩、材质、形态、功能、风格等维度
- **趋势分析**: 识别当前设计趋势和未来发展方向
- **案例展示**: 提供具体的设计案例和参考链接
- **日报生成**: 自动生成结构化的 Markdown 格式设计日报

### 📦 覆盖产品类别
1. **相机包与保护套** - Camera Bags & Cases
2. **照片展示框** - Photo Frames & Display
3. **相册与存储** - Photo Albums & Storage
4. **配件** - Accessories
5. **DIY与定制** - DIY & Customization

## 使用方法

### 基础用法

```bash
# 生成今天的设计日报
"帮我收集拍立得相机包的设计元素，生成今天的设计日报"

# 针对特定产品类别
"我想了解照片展示框的设计趋势，重点关注日式简约风格"

# 收集最近的设计创新
"收集最近一个月的拍立得周边产品创新设计案例"
```

### 高级用法

```bash
# 深度研究模式
"对拍立得周边产品市场进行全面分析，包括竞品对比和用户偏好"

# 特定风格研究
"研究复古风格的拍立得相机包设计，提供具体案例和色彩搭配方案"

# 材质创新研究
"收集环保材料在拍立得周边产品中的应用案例"
```

## 工作流程

1. **需求确认**: 明确研究范围、产品类别、时间范围等参数
2. **多源搜索**: 并行执行多个搜索查询，收集设计数据
3. **数据提取**: 从搜索结果中提取关键设计元素
4. **分类整理**: 将设计元素按色彩、材质、形态等维度分类
5. **报告生成**: 生成结构化的 Markdown 格式设计日报

## 输出格式

生成的日报包含以下部分：

- 📊 **设计趋势概览** - 核心趋势总结
- 🎨 **设计元素分析** - 色彩、材质、形态、功能、风格详细分析
- 💡 **设计灵感** - 具体案例展示
- 📈 **市场洞察** - 用户偏好、价格区间、热门品牌
- 🔗 **参考资源** - 设计网站、产品链接、灵感图库
- 📝 **设计建议** - 短期和长期设计方向建议

## 配置

### 环境变量
```bash
# 必需
TAVILY_API_KEY=tvly-your-api-key

# 可选
DESIGN_REPORT_OUTPUT_DIR=./design-reports
DEFAULT_SEARCH_DEPTH=advanced
DEFAULT_MAX_RESULTS=10
```

### 认证设置
参考 `research` 和 `search` skill 的认证方式：
1. OAuth 认证（推荐）- 首次运行时自动引导
2. API Key - 在 `~/.claude/settings.json` 中配置

## 最佳实践

### 搜索策略
1. **多角度搜索**: 使用不同的关键词组合获取多样化结果
2. **时间范围**: 使用 `time_range` 参数获取最新趋势
3. **搜索深度**: 使用 `advanced` 模式提高结果质量
4. **域名过滤**: 聚焦于专业设计网站

### 数据质量
1. **交叉验证**: 从多个来源验证信息
2. **相关性过滤**: 聚焦于设计相关内容
3. **定期更新**: 设计趋势变化快，需定期更新
4. **历史归档**: 建立历史数据库追踪趋势变化

### 报告生成
1. **具体化**: 提供具体案例而非抽象描述
2. **可视化**: 尽可能包含参考图片
3. **上下文**: 说明趋势的重要性
4. **可操作**: 提供明确的下一步建议
