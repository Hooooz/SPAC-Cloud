# China Trade Policy Weekly - 中国对外贸易政策周报生成器

## 简介

这是一个专门用于收集和分析中国对外贸易政策、国际贸易事件及政策驱动的贸易变化的专业 skill，能够自动生成高质量的贸易政策周报。

## 功能特点

### 🎯 核心功能
- **政策法规追踪**: 实时追踪关税、贸易协定、进出口管制等政策变化
- **时事动态分析**: 收集贸易摩擦、贸易谈判、国际组织动态
- **行业影响评估**: 分析政策对不同行业的影响
- **数据统计分析**: 整合进出口数据和贸易统计
- **风险预警提示**: 识别和评估贸易风险

### 📦 覆盖领域
1. **政策法规** - 关税政策、贸易协定、进出口管制、检验检疫、外汇管理
2. **时事动态** - 贸易摩擦、贸易谈判、国际组织、地缘政治
3. **行业影响** - 电子信息、纺织服装、机械设备、农产品、新兴领域
4. **数据统计** - 进出口数据、国别分析、商品结构

## 使用方法

### 基础用法

```bash
# 生成本周贸易政策周报
"帮我生成本周的中国对外贸易政策周报"

# 特定主题分析
"我想了解最近中美贸易摩擦的最新进展"

# 特定协定研究
"收集最近一个月RCEP实施对中国贸易的影响"

# 行业政策分析
"分析电子信息行业的最新贸易政策变化"
```

### 高级用法

```bash
# 特定国家/地区
"分析中国与东盟的贸易政策变化和合作进展"

# 特定政策类型
"收集最近一个月中国关税政策调整的情况"

# 深度研究模式
"对中国对外贸易政策进行全面分析，包括政策影响和应对策略"
```

## 工作流程

1. **需求确认**: 明确时间范围、关注重点、目标市场、行业聚焦
2. **多源搜索**: 并行执行政策、时事、数据、行业搜索
3. **内容分析**: 分类整理政策信息，评估影响程度
4. **报告生成**: 生成结构化的 Markdown 格式周报

## 输出格式

生成的周报包含以下部分：

- 📋 **本周概要** - 核心要点和数据快览
- 📜 **政策法规动态** - 新出台政策、政策调整、政策解读
- 🌍 **国际贸易动态** - 贸易摩擦、贸易谈判、国际组织
- 📊 **贸易数据分析** - 总体情况、国别分析、重点商品
- 🏭 **行业影响分析** - 各行业政策影响和应对建议
- ⚠️ **风险提示** - 高中风险事项预警
- 💡 **专家观点** - 专业分析和建议
- 📅 **下周关注重点** - 政策预期、重要事件、数据发布
- 📝 **应对建议** - 短期措施和长期策略

## 最佳实践

### 搜索策略
1. **权威来源**: 优先搜索官方网站（商务部、海关总署等）
2. **多维度搜索**: 政策、时事、数据、行业并行搜索
3. **时效性**: 使用 `time_range` 参数获取最新信息
4. **深度分析**: 使用 `advanced` 模式提高结果质量

### 内容质量
1. **准确性**: 核实政策信息的准确性，优先参考官方文件
2. **完整性**: 涵盖政策要点、影响分析、应对建议
3. **时效性**: 关注最新动态和变化
4. **实用性**: 提供可操作的应对措施

### 报告生成
1. **结构清晰**: 按类别组织内容，便于查找
2. **重点突出**: 标注紧急程度和影响级别
3. **数据支撑**: 用数据说话，增强说服力
4. **建议具体**: 提供明确可执行的应对措施
